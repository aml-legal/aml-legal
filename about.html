Verify it yourself

This checker runs client-side. No backend decides your score, and nothing you paste gets logged or transmitted anywhere, because there's no server here to send it to. If you don't want to take that on faith, open dev tools before you run a scan and watch the network tab: the only request that fires is a single call to the Tether contract. The OFAC match and the mixer-contract check happen entirely against data already sitting in the page you loaded.

The code itself is unminified, so View Page Source works the way it's supposed to. Search for isBlackListed and you'll land on the exact function call your browser makes against the USDT contract. Search for any wallet address from the data-sources table below and you'll find it sitting in a plain array.

Methodology, in short

Six named checks run on every scan. Right now, exactly one of them is genuinely live: the Tether freeze read above. The OFAC and mixer-contract checks are matched against real data that was pulled at a point in time rather than queried on the spot, mainly because OFAC doesn't expose anything a browser can call directly. The remaining three checks — FATF jurisdiction risk, scam labels, counterparty tracing — aren't built yet, and they're labeled that way rather than quietly absorbed into your score. The full per-check breakdown lives on the main checker page.

OFAC has no browser-callable API

Its sanctions list ships as a bulk XML/CSV export built for server-side ingestion, not client-side fetch calls, and there's no documented CORS support that would let a browser read it directly. A fully static site with no backend can't query that live. Pulling the full file periodically and shipping it as a dated snapshot, the way the data sources above are sourced, is the honest workaround.

Limitations, stated plainly

  • The OFAC snapshot covers Bitcoin, Ethereum, Tron/USDT, Litecoin, Monero, Bitcoin Cash, Ethereum Classic, BNB Chain and Zcash addresses. It does not cover Solana — the extraction tool this site relies on doesn't parse Solana addresses out of OFAC's file yet.
  • A "clear" result means not on this list as of the pull date — not verified against every sanction OFAC has ever issued, and not a guarantee the address stays clean tomorrow. Designations can be added anytime.
  • Tether's live freeze check only works for the Ethereum ERC-20 contract. TRC-20 and BEP-20 USDT use different contracts this build doesn't call.
  • FATF jurisdiction risk, scam/phishing labels, and counterparty tracing are not implemented — see the methodology note above for why, and don't let their absence from your score read as "clean" on those fronts.
